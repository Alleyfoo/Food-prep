# R5 conflicts between sources

Conflicting instructions are kept as separate versions in
`processing_conditions.yaml`, each with its sources. Nothing is averaged or
reconciled. The full list (43 conflicts on pairs, 31 alternative sequences) is
in `condition-tables.md` and `sequence-tables.md`. This page lists the ones that
change what a cook does, grouped by kind.

Conflicts at two levels:
- **within a step**: how long, how hot, how far;
- **between sequences**: sources that split the work differently. These are
  alternatives, not versions of one number. A long covered bake of raw slices
  and a blanch plus a shorter bake both work. A model that merged them would
  describe neither.

## Step-level: the ones that matter at the stove

| Step | Versions | Why it matters |
| --- | --- | --- |
| Rutabaga, how soft at the end of the gratin | some give, al dente (Q231) / no resistance, completely tender (Q232, Q233, Q234) | the kitchen test's main judgement; both are documented doneness |
| Rutabaga blanch | 3-5 min (G1, Q231, Q232, Q233) / about 10 min, almost tender (G16, G18) | the blanch is readiness either way; the 10-min version leaves less to the bake |
| Gratin cover | covered first (Q201, Q225, Q231, Q234) / uncovered, covered only if browning (Q237, Q230) | Finnish kermaperunat recipes split on this |
| Cabbage roll cover | not stated by any Finnish source / covered with broth (Q313, Q317, N9) | the napa test's "bake covered" comes from outside Finland |
| Rice for rolls | half-cooked or al dente (Q301, Q311, Q317, N10) / fully cooked (Q312, E12a, E12b, Q313) | half-cooked rice finishes in the oven; fully cooked rice needs liquid kept low |
| Cabbage head boil | about 5 min with repeat dips (Q310, Q311) / 10-20 min (E12a, Q302) / about 1 h (Q303) | every Finnish source agrees on the endpoint (leaves come away as they soften), not the time |
| Onion shell | still firm, lightly crisp (Q326, Q335) / cooked through first (Q335, second method) | the same page gives both, for two different bakes |
| Rosti potato | firm core, just bissfest (Q204, Q205, Q221) / just soft (Q223, E1a) | a known disagreement, now with Swiss sources on both sides |
| Chickpea soak | at least 4 h (Q118) / overnight (M2a, Q116) / 24 h (M2b, Q107, Q111) | all agree on the endpoint (swollen, raw, chops with a knife) |
| Urad dal soak | overnight (A3b) / an upper limit of 3-8 h (A3a, Q122-Q124) | a limit with a failure (oily vada) against no limit |
| Black-eyed bean soak | minutes (Q125, Q126, Q129) / 15 min-1.5 h (A18b, A19a) / overnight (Q132); hot water (Q132) against never hot (A19a) | the endpoint (skins slip off) is agreed |
| Grind fineness | coarse (P4, Q108, Q121) / fine (P1-P3, Q109, Q111) | for peas, P4 ties fine to dense falafel |
| Falafel rest | none (Q109, M2a) / required or it falls apart (Q114, Q115) | the chill is a make-ahead point either way |
| Courgette salting | salt then squeeze (M4a, Q401, Q405) / squeeze only (M3a, M3b, Q400) / no dewatering (Q408, A9b) | no source compares them |
| Patty oven | 180-185 C 30-45 min / 200 C fan 20 min / 225-250 C 10-20 min | the done-when (golden both sides) is agreed |
| Simmered potato, make ahead | simmer the day before (Q225) / never stop halfway (Q235) | a direct contradiction on batch preparation |
